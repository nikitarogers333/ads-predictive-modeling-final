# Original Assignment Prompt

## Introduction

This assignment will evaluate the application of predictive modeling techniques introduced in this course. You and your teammate(s) will work closely to find a dataset, clean and pre-process it, and perform a comprehensive predictive modeling analysis on the data using R. It is strongly recommended that you and your team use and practice GitHub for version control and collaboration. It is also necessary to create and add a README file to your GitHub repository. For creating the executive summary PowerPoint deck, you should review the "How to Communicate with Non-technical Stakeholders" tips and apply them to your presentation.

## Assignment Timeline

Module 2, by the end of Week 2:

- Instructor has assigned you to a 2-to-3-person group.
- Locate team members and review assignment requirements.

Module 5, by the end of Week 5:

- Select and introduce a dataset.
- Team representative submits the "Team Assignment Status Update Form."

Module 7, by the end of Week 7:

- Submit one 10-15 minute video presentation by all team members.
- Submit one PDF/HTML document containing technical report explanation for analyses, interpretations, 10-12 pages, and code appendix.
- Submit one PDF or PPT document, at most 5 slides, containing an executive summary for a non-technical audience.

## Assignment Dataset

You are responsible for finding a dataset for this assignment. Several free data resource links are provided within the Resources page on the MS-ADS GitHub website.

## Requirements

Divide the work equally between team members for the following steps, and everyone needs to code. You are expected to write high-quality, efficient, and readable code in R. This assignment requires a video presentation, technical report, and executive summary PowerPoint presentation.

## Video Presentation

Give a 10-15 minute presentation based on the technical report.

Include technical explanation of:

- Clearly defined problem statement and data description.
- Exploratory Data Analysis.
- Data pre-processing.
- Data splitting.
- Model building strategies.
- Model performance and hyperparameter tuning.
- Results and final model selection.
- Optional R Shiny web application demonstration.
- Discussion and conclusion, especially how the problem was framed as a predictive modeling solution.

Audience: data science peers and other technical viewers with knowledge of data science methods and techniques.

## Technical Report

Include:

- Clearly defined problem statement.
- Analysis of the data.
- Detailed solution.
- Graphs and output tables only if used in the discussion.
- Clear organization for statistically literate and technical audience.
- Case-study style organization similar to course examples.

Suggested subsections:

- Problem statement and justification for proposed approach.
- EDA, graphical and non-graphical representations of relationships between response variable and predictors.
- Data wrangling and pre-processing, including missing values, outliers, correlated features, etc.
- Data splitting, including training, validation, and test sets.
- Model strategies, research questions, and appropriate analytics methods.
- Validation and testing, including tuning and evaluation.
- Results and final model selection.
- Discussion and conclusions.
- Appendix with reproducible and clean R code.

## Executive Summary PowerPoint

Requirements:

- No longer than 5 slides.
- Introduce problem statement.
- Discuss solutions explored.
- Describe conclusions for non-technical audience.
- Be intelligible to someone who does not know predictive modeling techniques.
- Treat audience as Director, VP, or executive-level audience.
- Present analysis like a story instead of technical report.
- Make final model results understandable.

## Deliverables And Submission Format

### Video Presentation

- Submit video file, `.mp4`, or viable link to recorded presentation.
- Video should demonstrate narrated slides, superset of executive summary slides.
- Use screencasting tool such as Zoom.
- Ensure sound quality is good.
- Each member presents equal portion when team-based.
- Export video as `.mp4`.

### Technical Report

Submit one PDF/HTML document that combines:

1. Technical report.
2. Appendix.

Implement assignment in R using R Markdown.

Within R code:

- Import all packages used in first code cell.
- Use code cells for code and comments.
- Use markdown cells for headings and descriptions.
- Generate PDF/HTML document containing code, comments, and results.
- Attach this document as appendix to technical report.

Technical report should use APA 7 style. Technical report without appendices, including text and selected tables/graphs, should be 10-12 pages. Combine technical report and appendix into a single document, then convert to PDF/HTML.

### Executive Summary

Submit executive summary slides in PPT or PDF format.

By Day 7 of Module 7, designate one team member to submit all three deliverables.

Suggested file naming:

- `Report-Team1.pdf`
- `Executive_Summary-Team1.pptx`

## AI-Assisted Tools

AI-assisted tools such as ChatGPT, Gemini, and GitHub Copilot should be used to enhance learning, not replace it. If AI tools are used, explicitly disclose, cite, and explain their contributions, for example comments in code or footnotes in reports. Submitting AI-generated code or written content without sufficient understanding, modification, and justification is unacceptable. Proper attribution is essential for academic integrity and learning.
