# Submission Checklist

## Module 5 Status Update

- [ ] Team selected dataset
- [ ] Problem statement drafted
- [ ] Response variable identified
- [ ] Team representative submitted status update form

## GitHub Repository

- [ ] Repository created
- [ ] `README.md` added
- [ ] Data source documented
- [ ] Code committed regularly
- [ ] Team members collaborated through commits/branches
- [ ] AI-use disclosure added where relevant

## Technical Report

- [ ] Written in R Markdown
- [ ] Packages imported in first code chunk
- [ ] Problem statement included
- [ ] Dataset described
- [ ] EDA included and discussed
- [ ] Data cleaning/pre-processing explained
- [ ] Data splitting explained
- [ ] Model strategies explained
- [ ] Hyperparameter tuning documented
- [ ] Validation/test metrics reported
- [ ] Final model selected and justified
- [ ] Limitations and future work included
- [ ] APA 7 style followed
- [ ] Appendix/code included
- [ ] Exported to PDF or HTML
- [ ] Filename: `Report-Team1.pdf` or equivalent

## Executive Summary

- [ ] 5 slides or fewer
- [ ] Non-technical language
- [ ] Problem stated clearly
- [ ] Solutions explored
- [ ] Final recommendation
- [ ] Limitations/next steps
- [ ] Filename: `Executive_Summary-Team1.pptx` or PDF

## Video Presentation

- [ ] 10-15 minutes
- [ ] All team members present equal portion
- [ ] Technical explanation included
- [ ] Sound quality checked
- [ ] Exported as `.mp4` or uploaded as link
- [ ] Includes narrated slides

## Final Submission

- [ ] Video file/link submitted
- [ ] Technical report PDF/HTML submitted
- [ ] Executive summary PPT/PDF submitted
- [ ] File naming checked
